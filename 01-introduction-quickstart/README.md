## Module 01 — Introduction & QuickStart

Welcome to Module 01. This module gives you a short, practical introduction to the Model Context Protocol (MCP) and helps you connect a free MCP server to your IDE so you can try it right away.

### What you'll learn
- Understand at a high level what MCP is and how it fits into a client–server model
- Learn the three core MCP primitives: tools, resources, and prompts
- Connect a free MCP server to your IDE and run simple test prompts

### Who this is for
- Developers new to MCP who want a quick, hands-on start
- Anyone who prefers learning-by-doing with minimal setup

### Prerequisites
- Basic Python and command-line familiarity
- Cursor IDE installed (or another IDE with MCP support)

### Navigation
- Conceptual overview: see `conceptual-overview.md`
- QuickStart guide: see `quickstart-guide.md`
- Try-it-yourself mini‑exercises: see `exercises/try-it-yourself.md`

### Structure
This module has two short parts:
- Conceptual Overview (about 5 minutes): high-level mental model of MCP and its primitives
- QuickStart (about 10 minutes): connect a free server and test a few prompts

When you finish, you’ll have a working MCP connection and a clear sense of what MCP enables.

### Time estimate
30–45 minutes total (5 min overview, 10 min quickstart, 10–20 min exercises)
